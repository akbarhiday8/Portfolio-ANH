# Audit Website dan CMS — 12 September 2026

## Status akhir lokal

- Lint: lulus tanpa peringatan.
- Build produksi: lulus.
- Audit dependensi npm: 0 kerentanan.
- CRUD: tambah, baca, ubah, hapus, urutkan, draft, dan publikasi tervalidasi di server.
- Riwayat: versi sebelum perubahan disimpan, maksimal 10 revisi per konten.
- Autentikasi: satu admin, registrasi tertutup setelah akun tersedia, sesi aman, logout, reset akun, dan pembatasan percobaan login.
- Media: validasi MIME/signature, batas ukuran, optimasi gambar di browser, progres dan pembatalan unggah, pembersihan aset tidak terpakai, serta deduplikasi SHA-256.
- SEO: metadata, robots.txt, sitemap.xml, halaman 404, error boundary, dan loading state.
- Keamanan HTTP: CSP, frame denial, nosniff, referrer policy, permissions policy, dan cache immutable untuk aset statis.
- Responsif: website publik dan drawer CMS diuji pada ukuran desktop dan mobile.

## Temuan yang diperbaiki

1. Validasi sebelumnya hanya mengandalkan antarmuka. Semua mutasi sekarang divalidasi ulang dengan Zod pada server.
2. Konten belum lengkap sebelumnya dapat dipublikasikan. Publikasi sekarang memiliki persyaratan berbeda untuk tiap koleksi.
3. Slug ganda, ID pengurutan tidak lengkap, dan koleksi URL yang tidak cocok sekarang ditolak.
4. Sidebar CMS mobile sebelumnya terpotong. Drawer sekarang memakai ukuran viewport, body scroll lock, fokus tombol tutup, dan dukungan Escape.
5. Dependensi komponen yang tidak dipakai sudah dihapus. Tooling Cloudflare/Vite/React diperbarui.
6. Media yang diganti atau dihapus dibersihkan otomatis setelah dipastikan tidak direferensikan konten lain.
7. API admin sekarang memakai `Cache-Control: no-store`; mutasi produksi tanpa header Origin ditolak.
8. Kegagalan database publik sekarang tercatat di log sebelum fallback konten bawaan digunakan.

## Ukuran hasil build

- JavaScript + CSS klien: sekitar 764,2 KB mentah / 222,8 KB gzip untuk seluruh chunk build.
- Seluruh aset publik build: sekitar 3,64 MB; browser hanya mengambil aset yang dipakai oleh halaman dan breakpoint aktif.
- Foto hero memakai WebP dengan `sizes` responsif dan prioritas hanya pada gambar utama.

## Batas audit

- Logout pemilik tidak diuji melalui UI pada sesi utama agar akses admin lokal tidak terputus; route, penghapusan sesi, dan pengosongan cookie telah diperiksa pada kode.
- Pemindaian malware dokumen memerlukan layanan eksternal khusus dan belum ditambahkan. Upload dibatasi tipe, ukuran, ekstensi, dan magic bytes.
- Pengujian lint/build/audit tidak menggantikan pengujian beban produksi setelah domain, CDN, dan Supabase aktif.
